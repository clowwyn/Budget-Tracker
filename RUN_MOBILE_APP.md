# 📱 Run the Mobile App - Simple Instructions

## ✅ No Backend Needed!

This mobile app is **100% offline**:
- All data stored on your phone (SQLite)
- No internet required
- No servers to set up
- Private and secure

---

## How to Run It

### 1. Install Expo Go on Your Phone

Download **Expo Go** app:
- **iPhone:** https://apps.apple.com/app/expo-go/id982107779
- **Android:** https://play.google.com/store/apps/details?id=host.exp.exponent

### 2. Start the Mobile App

Open terminal/PowerShell and run:

```bash
cd "C:\Users\whayne\OneDrive\Desktop\Baby Budget Tracker\mobile"
npm start
```

### 3. Scan the QR Code

A QR code will appear in your terminal.

**Scan it:**
- **iPhone:** Open Camera app → point at QR code
- **Android:** Open Expo Go app → tap "Scan QR Code"

### 4. App Opens on Your Phone! 🎉

The Bloom Budget app loads on your device.

## Troubleshooting

**Can't scan QR code?**
- Make sure phone and computer are on same WiFi
- Press `t` in terminal to try tunnel mode

**App crashes?**
- Make sure Expo Go is updated
- Try restarting: press `r` in terminal

**Need help?**
- Press `?` in terminal to see all commands
