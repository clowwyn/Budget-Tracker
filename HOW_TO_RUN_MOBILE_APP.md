# 📱 How to Run the Bloom Budget Mobile App

## ✅ The REAL Mobile App is Ready!

Located in: `/mobile-app/` directory

## Quick Start (Easiest Method)

### 1. Install Expo Go on Your Phone

**Download Expo Go:**
- **iPhone:** https://apps.apple.com/app/expo-go/id982107779  
- **Android:** https://play.google.com/store/apps/details?id=host.exp.exponent

### 2. Start the App
```bash
cd mobile-app
npm start
```

### 3. Scan the QR Code

A QR code will appear in your terminal.

**Scan it with:**
- **iPhone:** Open Camera app → Point at QR code
- **Android:** Open Expo Go app → Tap "Scan QR Code"

### 4. The App Opens on Your Phone! 🎉

The Bloom Budget app will load directly on your device.

## Alternative: Run on Emulator/Simulator

### iOS Simulator (Mac only)
```bash
cd mobile-app
npm run ios
```

### Android Emulator
```bash
cd mobile-app
npm run android
```
*Requires Android Studio with emulator setup*

## Troubleshooting

### Can't scan QR code?
- Make sure phone and computer are on same WiFi
- Try pressing `t` in terminal to switch to tunnel mode

### App not loading?
- Check that Expo Go is installed
- Restart the dev server: Press `r` in terminal
- Clear cache: Close Expo Go and reopen

### Need to stop the server?
Press `Ctrl + C` in the terminal
