# UX Context

## Dashboard

Show:
- total balance
- accounts
- recent transactions
- income
- expenses

Primary action:
`+`

The + action should make adding an account or transaction obvious.

## Account detail

Show:
- account name
- account type
- current balance
- transaction history
- edit/delete actions

## Transaction form

Fields:
- transaction type
- amount
- account
- category
- date
- note

## UX states

Every important screen should consider:
- loading
- empty
- success
- validation error
- database error
- destructive confirmation

## Design principle

Optimize for entering a transaction in a few taps.
